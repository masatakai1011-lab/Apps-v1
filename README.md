# 株・FX監視

持っている株・通貨の **値段** と **関係するニュース** を、1枚のページにまとめて見るためのものです。
iPad とパソコンで見やすいように作っています。

- 今日のまとめ：持ち株・市場全体・これからの予定を4行の文章で自動作成。「音声で聞く」を押すと読み上げます
- 世界の市場の帯：日経平均・NYダウ・原油・金などの値段が画面の上に流れます
- 市場の時間：東京・ロンドン・ニューヨークのどこが開いているか、いまがよく動く時間か
- 為替・株価：1つの銘柄を1枚の横長カードにまとめています
  - 値段と前の日からの動き、グラフ（1日・1か月・1年を切りかえ。高値・安値つき）
  - 含み損益：持っている数と買い値を画面で登録すると、損得と今日の増減を表示（その端末の中だけに保存され、公開されません）
  - 動きの珍しさ：ふだんの何倍の動きか、この1年で何番目の大きさか（大きいときはカードが光ります）
  - 仲間とくらべる：同じ業界の会社や市場全体と並べて「業界全体の動きか、この銘柄だけか」を判定
  - グラフの ◆ しるし：この1か月で大きく動いた日。押すとその日のニュースが開きます
  - これからの予定（関係する重要発表・決算）、関係する地域の騒がしさ、関連ニュース
- 市場の状況：恐怖指数（VIX）の温度計と、今週の大事な予定（持ち株に関係するものに印、次の重要発表までの残り時間）
- ニュース映像：海外ニュースのライブ配信と、経済ニュースの動画3本
- 世界情勢：世界地図の上に、地域ごとのニュースの多さ（騒がしさ）と最新の見出し。持ち株（日本）と関係する地域を線でつなぎます
- お知らせ：持ち株が「急落・急上昇」したら、GitHub のお知らせ（通知・メール）で届きます（同じ銘柄は1日1回）
- 更新：為替がよく動く時間に合わせて自動で最新になります（日本時間）
  - 平日：6時、8〜10時、12時、15時〜翌2時は毎時、21時半〜翌0時半は30分ごと
  - 土日：9時・15時・21時
  - ページを開きっぱなしにしていても、10分ごとに新しいデータを確かめて表示し直します

## 見たい株・通貨を変えるには

`watchlist.txt` を開いて書きかえるだけです。書きかえて保存すると、数分でページに反映されます。

```
トヨタ自動車, 7203
米ドル/円, USD/JPY, ドル円
```

- 日本の株は4けたの証券コード（285A のように英字が入るものも可）、通貨は「USD/JPY」のように書きます
- 3つ目にはニュースを探す言葉を書けます（省略すると表示名で探します）
- 「関係する地域」は `キオクシア の地域 → 中国・朝鮮半島・台湾, アメリカ` のように書きます（通貨は自動）
- 「比べる相手」は `キオクシア → 日経平均 ^N225, マイクロン MU` のように、矢印のあとに「名前 コード」を並べます

## 中身

| ファイル | 役目 |
|---|---|
| `watchlist.txt` | 見たい株・通貨のリスト |
| `scripts/update.py` | 値段とニュースを集めて `docs/data.json` に書き出す |
| `docs/index.html` | 1枚のページ |
| `docs/world.json` | 世界地図の形（`scripts/make_world_map.mjs` で作成） |
| `.github/workflows/update.yml` | 決まった時間に自動で更新する設定 |

値段は Yahoo! Finance、ニュースは Google ニュースから取得しています。
値段は少し遅れることがあります。売り買いの判断はご自身でお願いします。
