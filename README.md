# 株・FX監視

持っている株・通貨の **値段** と **関係するニュース** を、1枚のページにまとめて見るためのものです。
iPad とパソコンで見やすいように作っています。

- 世界の市場の帯：日経平均・NYダウ・原油・金などの値段が画面の上に流れます
- 為替・株価：前の日と比べてどれだけ動いたか、この1か月の動き（高値・安値つき）
- 市場の状況：恐怖指数（VIX）の温度計と、今週の大事な経済指標・持ち株の決算発表予定
- ニュースまとめ：海外ニュースのライブ配信、経済ニュースの動画3本、銘柄ごとの記事3件
- 世界情勢：世界地図の上に、地域ごとのニュースの多さ（騒がしさ）と最新の見出し
- 更新：為替がよく動く時間に合わせて自動で最新になります（日本時間）
  - 平日：6時、8〜10時、12時、15時〜翌2時は毎時、21時半〜翌0時半は30分ごと
  - 土日：9時・15時・21時
  - ページを開きっぱなしにしていても、10分ごとに新しいデータを確かめて表示し直します

## 見たい株・通貨を変えるには

`watchlist.txt` を開いて書きかえるだけです。書きかえて保存すると、数分でページに反映されます。

```
トヨタ自動車, 7203
米ドル/円, USD/JPY, ドル円
```

- 日本の株は4けたの証券コード（285A のように英字が入るものも可）、通貨は「USD/JPY」のように書きます
- 3つ目にはニュースを探す言葉を書けます（省略すると表示名で探します）

## 中身

| ファイル | 役目 |
|---|---|
| `watchlist.txt` | 見たい株・通貨のリスト |
| `scripts/update.py` | 値段とニュースを集めて `docs/data.json` に書き出す |
| `docs/index.html` | 1枚のページ |
| `docs/world.json` | 世界地図の形（`scripts/make_world_map.mjs` で作成） |
| `.github/workflows/update.yml` | 決まった時間に自動で更新する設定 |

値段は Yahoo! Finance、ニュースは Google ニュースから取得しています。
値段は少し遅れることがあります。売り買いの判断はご自身でお願いします。
